# Менеджер задач

Тестовый проект, разработанный с использованием 
[Yii2 Framework](https://github.com/yiisoft/yii2).

## Структура проекта

```
.docker/            Конфигурация и файлы данных Docker-среды
api/                Слой API
    components/     Глобальные компоненты
    config/         Конфигурация, специфичная для API
    controllers/    Контроллеры (роутинг)
    formatters/     Преобразование данных перед отдачей
    runtime/        Файлы, генерируемые во время выполнения
    web/            Корневая директория, доступная из веба
app/
    Commands/       Консольные контроллеры (роутинг)
    DTO/            Data Transfer Objects
    Interfaces/     Интерфейсы
    Models/         Модели (ActiveRecord)
    Repositories/   Репозитории
    Services/       Сервисы (бизнес-логика)
config/             Конфигурационные файлы приложения
migrations/         Миграции
```

## Требования

Для запуска dev-окружения требуется Docker и Docker Compose.  

## Установка

Сперва необходимо скачать себе файлы проекта любым удобным способом:

- Командой ```git clone```
- Через любой Git-клиент
- ZIP архив репозитория

Затем сохраните копию файла `.env.example` с новым названием (`.env`), 
и заполните его актуальными значениями (либо оставьте значения по-умолчанию). 
После этого запустите dev-окружение командой `docker-compose up -d`.

**В контексте dev-окружения, все упоминаемые далее команды выполняются внутри 
контейнера с php (`fpm`).**

Далее нужно установить пакеты приложения командой ```composer install```.
Затем применить миграции командой ```php yii migrate```.
